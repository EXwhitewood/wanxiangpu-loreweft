# 中文小说语篇级 AI 味

## 段落同构

常见结构：

```text
提出判断
解释判断
列出三个表现
总结判断的重要性
```

当多个连续段落重复同样句数、句长顺序、连接词和总结方式时，应触发 `paragraph_shape_repeat_count`。

## 语义复述

常见形式：

1. 动作已经表达情绪。
2. 旁白解释动作说明了什么。
3. 段尾再次总结人物的情绪或成长。

修复时保留最有力的一层。后句若保留，必须推进新事实、新后果或新的误解。

## 镜像句壳

- 不是 A，而是 B。
- 不仅 A，更 B。
- 真正重要的不是 A，而是 B。
- 答案很简单：B。
- B 的本质，是 C。

这些句式不是禁用项。只有重复、密集、缺乏真实逻辑功能时才失败。

## 情绪和道德过度整洁

模型倾向让人物：

- 很快准确说清自己的情绪；
- 在冲突后迅速互相理解；
- 获得正向成长或救赎；
- 给出完整道德结论；
- 清除矛盾、误解和不体面的动机。

成熟小说允许人物不知道自己为什么这样做，允许和解不完整，允许正确选择仍然带来难堪后果。

## 修复粒度

- Level 1：删除词句模板。
- Level 2：重排相邻句群。
- Level 3：重构目标段落的组织方式。
- Level 4：根据声纹重新建立观察、判断和节奏。
